CORREÇÃO DO ADMIN MASTER - PROJETO OFICINA

Este pacote contém três arquivos para o perfil temporário H2:
1. Funcao.java: adiciona o construtor público Funcao(String nome).
2. AdminMasterInitializer.java: cria ROLE_ADMIN_MASTER se ela não existir e depois cria o usuário.
3. application-test.properties: configura H2 em memória e credenciais locais de teste.

COMO APLICAR
1. Faça uma cópia de segurança dos três arquivos atuais.
2. Extraia este ZIP.
3. Copie cada arquivo para o mesmo caminho relativo dentro do seu projeto, substituindo o arquivo existente.
4. Abra o terminal na pasta backend (a pasta que contém pom.xml).
5. Execute:
   mvn spring-boot:run "-Dspring-boot.run.profiles=test"
